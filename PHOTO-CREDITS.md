# Image sources

This version intentionally removes the third-party Pexels photography used in the first redesign pass.

The homepage and service imagery now reference the existing optimized BZ Resources image assets already stored in the `DiamondBZResources/bz-resource` GitHub repository, including the original staffing, recruiting, screening, training, tracking, payroll, and workers' compensation photography.

The header/footer also use the original BZ logo asset from the existing repository.

Interior page heroes do not use stock photography. They use a graphic navy/blue brand treatment instead.
